# Settings foundation API

Issue #72, approved Figma sources 1964:86819 and 1827:50855; user amendments in settings-foundation.md.

- iOS SettingsEntryContent and AgentSettingsContent own native Lists/Sections. Do not wrap either in ScrollView. Use SettingsEntryContent(agentDestination: { AgentPreview(...) }) for native navigation. Legacy openAgent action initializer remains available. Both accept optional onShare; absent action stays a static reference.
- AgentSettingsDestination is a stable eight-case route contract (Swift lowerCamelCase, Kotlin PascalCase): pairedDevices, connectors, automations, cloudBrowser, memory, models, wallet, voice. Automations opens its own page (`1833:5080`) since the settled Settings-destinations decision. Available route sets default empty. iOS uses NavigationLink(value:) with host navigationDestination registration; Compose uses openDestination callback. Supply availability only after a real local destination exists.
- SettingsEntryDestination routes the entry rows: Swift agentSettings, billing, permissions, about, helpSupport (value routes passed as `availableRoutes` to the agentRoute initializer); Kotlin Billing, Permissions, About, HelpSupport (`availableDestinations` + `openDestination`, Agent settings keeps openAgent). Pages: Billing & Usage `1827:50803`, Permissions `1827:50821`, About `1827:50839`, Help & Support `2014:68798`. Rows outside the supplied set remain static references. Controls that need a missing service (automation runner, purchases, OS permission prompts or open-Settings, feedback/bug forms, shake detection) state a "Prototype boundary" instead of acting; About Terms/Privacy reuse the shared legal-document sheet; About Version takes the host build version. Fixtures: `SettingsPagesFixture.swift` / `.kt`.
- SettingsRowLabel composes ListRow, explicit Subtle/settings-size ContainedIcon (labelPrimary glyph on backgroundSecondary gray) and ListRowLabel. Swift label is content only; navigation/actions belong to the host. Compose owns its click action and single optional disclosure, since it has no List navigation chrome. A missing action gets no disclosure. Root non-Agent references remain static.
- Swift ListRow content initializer adds layout: .nativeList; native containers then own insets, separators and disclosure. Default standalone layout and all earlier initializers are unchanged. RemSection remains the custom-scroll adapter. Compose retains RemSection and content-slot ListRow.
- ListRowLabel supports title, optional subtitle, fill/hug title layout and titleAccessory slot on both platforms. Text uses semantic typography and wraps with Dynamic Type/font scaling.
- ContainedIcon adds an optional glyph size override (Swift glyphPointSize, Compose glyphSize), preserving old defaults. Current Figma Small means29/radius7, code settings; Figma Large means64/radius18. Primitive glyphs are15/30, while approved Settings instances use17. Legacy code small remains38.
- Share has only an optional action callback in this foundation. Root integration owns the system activity sheet/Android Sharesheet and the equivalent payload contract.
